# Forge app icon

Created with the built-in image generation tool. The mark combines a Git-branch F and download arrow in GitHub's dark, white and green palette.

- Source: `ForgeIcon-source.png`
- iOS: `../Forge/Assets.xcassets/AppIcon.appiconset/ForgeIcon.png` (opaque 1024 × 1024 PNG)
- Android: `../Android/app/src/main/res/drawable-nodpi/forge_launcher.png` (512 × 512 PNG, with native adaptive-icon masking)

The platform exports resize the source without changing the design.

## Generation prompt

Use case: logo-brand. Asset type: production iOS and Android launcher icon for Forge, an independent GitHub companion focused on Actions, releases and artifact downloads. Generate one square 1024x1024 opaque PNG. Full-bleed solid GitHub-dark charcoal (#0d1117) background to all four edges; the operating system will mask its corners. Center a distinctive, beautifully simple off-white (#f0f6fc) monogram that combines the capital letter F with a git branching diagram: broad crisp rounded strokes, two small circular branch terminals, and a short download-arrow ending on the main vertical stem in GitHub-success green (#3fb950). Make it feel like one coherent glyph, not several pasted symbols. The complete mark occupies the central 55% of the canvas, optically centered, strong silhouette, generous negative space, recognizable at 32 pixels, restrained GitHub native design language. Flat vector-like precision, perfectly clean edges. No wording, no separate letter labels, no Octocat, no border, no baked-in rounded outer corners, no gradient, no texture, no shadows, no glow, no mockup or device frame. Deliver only the final icon.
